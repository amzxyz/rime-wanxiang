# 候选切割机 (Lua)：输入过程中的精准切分

> **适用场景：** 当连续输入一串拼音后，候选长句的前半部分正确，但后半部分因为同音、近音或上下文预测出现偏差时，没有必要将整段编码删除后重新输入。此时可以使用“候选切割机”，先将正确部分上屏，再继续处理剩余编码。

万象通过 Lua 脚本实现了候选内容的定长切分。使用快捷键可以将首选候选的前 N 个字直接上屏，同时保留对应的剩余编码，便于继续选词或补充辅助码。

---

## 一、核心机制与操作指南

当候选框出现长句，且**首选词的前 N 个字完全正确**、后续内容出现错误时，不需要先上屏整个候选，可以直接使用组合键进行切分：

* **操作方式**：按下 **`Ctrl + 1~0`**（数字键 1 到 0 分别代表切出前 1 到 10 个字）。

* **执行效果**：

  1. 系统会立即将首选项的**前 N 个字直接上屏**。

  2. 与剩余文字对应的拼音编码会按照音节重新切分，并继续保留在输入区。

  3. 由于已经移除了前半部分编码的上下文影响，剩余编码会重新参与候选计算。此时如果首选已经正确，可以直接按空格上屏；需要进一步缩小候选范围时，也可以继续按 `Tab` 补充辅助码。

**实战示例：**

> 输入一串拼音后，首选出现 `今天下午开毁`，实际想输入的是“今天下午开会”。
>
> 此时直接按下 **`Ctrl + 4`**：
>
> `今天下午` 立即上屏。
>
> 输入区保留 `kai'hui`，剩余编码重新参与候选计算后，首选可能恢复为正确的 `开会`。确认无误后按空格上屏即可。

---

## 二、版本差异与处理方式 (Base vs Pro)

由于 Base 与 Pro 的编码结构不同，候选切割后的结果也会存在一定差异，需要根据实际版本选择后续操作：

* **标准版 (Base)**：主要由全拼或双拼编码参与候选计算，切割后剩余编码的结构相对简单。在长句输入过程中，如果前半部分候选正确，可以直接使用切割功能保留后半部分编码继续输入。

* **增强版 (Pro)**：Pro 版同时包含辅助码逻辑。切割完成后，剩余编码中原有的辅助码仍可能继续参与候选约束，因此重新计算出的候选不一定与预期一致。

  * **Pro 版处理方式**：如果切割后的候选不正确，可以多次按下 **单引号 `'`** 手动调整分词；如果剩余编码已经不便继续处理，也可以直接按下 `Esc` 清除残留编码，然后重新输入后半段。
