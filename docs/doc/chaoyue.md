# HarmonyOS NEXT (超越输入法) 部署指南

HarmonyOS NEXT 无法直接使用传统 Android 输入法。在该平台使用万象，需要通过支持 Rime 引擎的 **超越输入法** 导入方案并完成部署。

请按照以下流程准备并导入万象方案和对应皮肤。

---

### 1. 下载并安装前端应用和方案文件

请在华为手机的 **应用市场 (AppGallery)** 中搜索并安装 **【超越输入法】**。

随后下载最新版的**万象方案包**和**语法模型**：

**下载万象拼音方案**

请根据当前网络环境选择下载源，前往 Releases 页面获取最新版方案压缩包（`.zip`）：

* **国内节点 (CNB)**：[:octicons-link-external-24: 点击前往下载](https://cnb.cool/amzxyz/rime-wanxiang/-/releases)

* **GitHub**：[:octicons-link-external-24: 点击前往下载](https://github.com/amzxyz/rime-wanxiang/releases)

**下载语法模型**

* [:octicons-download-24: wanxiang-lts-zh-hans.gram](https://cnb.cool/amzxyz/rime-wanxiang/-/releases/download/model/wanxiang-lts-zh-hans.gram)

---

### 2. 在电脑端准备 ZIP 部署包

与 Windows、macOS 端直接放置方案文件的方式不同，超越输入法通过**导入 ZIP 压缩包**读取方案和皮肤，因此需要先整理对应的压缩包。

1. **准备方案包 (`Rime.zip`)**：

   * 新建一个文件夹，命名为 `Rime`。
   * 将下载的万象方案压缩包解压。
   * 将解压后的所有方案文件、文件夹，以及 `wanxiang-lts-zh-hans.gram` 语法模型，**全部放入 `Rime` 文件夹中**。
   * 将整个 `Rime` 文件夹重新压缩，最终得到 `Rime.zip`。
2. **准备皮肤包 (`VGHFly.zip`)**：
   请通过下方按钮下载适用于超越输入法的万象主题皮肤包：

   [:octicons-download-24: 点击下载 VGHFly「万象」皮肤包](../files/VGHFly.zip){ .md-button .md-button--primary style="margin-top: 10px;" }

---

### 3. 传输文件至手机

将准备好的方案包 **`Rime.zip`** 和皮肤包 **`VGHFly.zip`** 传输到手机，并放入本地存储的 **`Download`（下载）** 目录。

可以使用微信、设备互传、数据线等方式完成文件传输。

---

### 4. 在应用内导入与启用

打开手机上的【超越输入法】APP，按照以下步骤进行操作：

1. **导入方案**：进入方案导入功能，选择 `Download` 目录中的 `Rime.zip`。
2. **导入皮肤**：进入皮肤导入功能，选择 `Download` 目录中的 `VGHFly.zip`。
3. **选择并启用**：在应用的方案列表和主题列表中，分别选择刚刚导入的万象方案和对应皮肤。

---

### 5. 执行重新部署

完成导入后，检查方案列表中是否已经出现“万象拼音”或“万象拼音 Pro”等对应方案。

> **如果方案没有出现，或修改配置后需要重新生效**：点击页面右上角的 **【刷新】** 按钮。超越输入法会重新执行 Rime 的部署与编译流程，部署完成后即可继续使用。

!!! abstract "关于皮肤深度定制"
本教程提供的是可以直接导入使用的主题包。如果需要进一步修改鸿蒙端皮肤，请查阅 [超越输入法官方文档]。超越输入法的皮肤参数与电脑端及同文输入法并不通用，但配置语法与同文输入法存在一定相似之处。

---

### 6. 初始指令与个性化切换

部署成功后，万象默认使用以下输入方案：

* **Base 标准版**：默认开启 **全拼**。
* **Pro 增强版**：默认开启 **自然码双拼**。

!!! tip "建议执行一次方案切换指令"
    即使当前默认方案已经符合您的使用习惯，也建议通过斜杠指令主动选择一次所需的拼音方案，以确保相关配置与当前输入方式保持一致。

    **操作方法**：在任意输入框的中文输入状态下，输入对应的斜杠指令。完成切换后，返回超越输入法 APP，**再次点击【刷新】执行重新部署**，配置即可生效。
