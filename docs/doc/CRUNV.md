# 字母引导功能：C Compose / R 人民币大写 / U Unicode / N 日期 / V 计算器

> **以下功能均通过大写字母触发。输入时请使用 `Shift + C/R/U/N/V` 得到对应的大写字母，再继续输入后续内容。**

---

## **C** 模式：Compose 合成字符

C 模式参考 Linux/X11 的 Compose 输入机制，用于输入键盘上没有直接按键的特殊符号、带调字母及其他组合字符。

* **触发方式**：输入大写 `C`，然后依次键入 Compose 序列。命中有效 Compose 序列后，对应结果会进入首选，此时可以按空格上屏。

* **标点命中机制**：所有可键入标点（`!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~` 等）均采用命中判断。只有加入当前标点后，新序列能够**完整命中**某条 Compose 编码，或者仍是某条 Compose 编码的**有效前缀**时，该标点才会继续参与组合。

  如果加入标点后已经不存在可继续匹配的 Compose 序列，则视为当前组合结束。此时引擎会将**此前输入的内容 + 当前标点对应的中文全角标点**直接上屏，并退出 C 模式。

  这样既可以正常处理包含标点的有效序列，例如 `C,` `A` → `Ą`、`C!` → `¡`、`C:-` → `÷`，也可以避免无效序列持续停留在 C 模式中。

  * 示例：`C` `w` `,` → 上屏 `Cw，`。由于 `w` 后继续输入逗号无法形成有效 Compose 序列，因此原内容与中文逗号直接上屏。
  * 示例：`C` `a` `,` `,` → 上屏 `Ca，`。`Ca,` 已经命中，再输入一个逗号无法构成新的有效序列。
  * 反之，`C` `,` `A` 属于有效序列，可以正常合成 `Ą`。

* **小键盘与主键区分工**：小键盘中所有可直接输入字符的按键，包括数字 `0-9`、运算符 `+-*/=` 以及小键盘 `,` `.`，均可以直接参与 C 模式组合，并且不会吞键。小键盘 Enter 则透传给 Rime 默认处理。

  主键区数字 `1..9,0` 在 C 模式下仍然用于选词，主键区的 `-`、`=` 仍用于翻页，并继续交由 Rime 默认处理，不会进入 Compose 序列。

* **主键区补充输入**：只有主键区可用时，可以按住左侧 `Alt`，再使用主键区数字键或 `-`、`=` 参与 Compose 序列输入。

* **输入示例**：输入大写 **`C`** 后继续输入：

  1. `'` `e` → `é`（重音字母）

  2. `"` `a` → `ä`（变音字母）

  3. `o` `c` → `©`（版权符号）

  4. `-` `-` → `—`（破折号）

  5. `(` `c` `)` → `©`、`?` `?` → `¿` 等，目前共收录 **1229** 条 Compose 合成序列。

## **R** 模式：数字与人民币金额大写

R 模式用于将阿拉伯数字转换为中文数字、人民币金额大写等格式，适用于报账、合同及其他需要规范数字书写的场景。

* **触发方式**：输入大写 `R`，后接一串阿拉伯数字。

* **输入示例**：输入 **`R1234`** 后，可以得到：

  1. `一千二百三十四`（标准中文数字）

  2. `壹仟贰佰叁拾肆元整`（人民币金额大写）

  3. `一二三四`（逐位中文数字）等多种格式。

!!! success "R 模式选词方式"
    为避免数字键与输入内容产生冲突，R 模式提供了额外的候选选择方式：


    * **字母选词**：可以直接使用键盘上的 **`q, w, e, r, t, y...`** 选择对应候选，其中前几个字母依次对应第 1 到第 6 个候选项。

    * **方向键选词**：也可以继续使用 `↑`、`↓` 方向键移动候选焦点，再按回车确认。

## **U** 模式：Unicode 编码输入

U 模式用于通过 Unicode 编码直接输入对应字符，适合已经知道字符编码、但不知道其读音或输入编码的情况。

* **触发方式**：输入大写 `U`，后接十六进制 Unicode 编码。

* **输入示例**：输入 **`U62fc`**，候选框会直接给出对应汉字「拼」。

---

## **N** 模式：日期输入

在大写字母 `N` 后输入数字，可以进入数字日期模式。输入完成后，可以直接使用数字键选择候选，同时支持使用 `q, w, e...` 对应候选位置进行选择。

* **4 位数字模式（月日）**：输入 `N0101` 或 `N0312`，系统会自动补充当前年份。

* **8 位数字模式（年月日）**：输入 `N20250315`，直接生成对应的完整日期格式。

> **自定义说明**：N 模式支持调整输出类型、日期格式、候选顺序和候选数量，具体配置方式可参考时间日期相关配置。

## **V** 模式：超级计算器

V 模式提供表达式计算、数学函数、方程求解、几何计算、数列、数论和单位换算等功能。底层由 `super_calculator.lua` 实现，注册为 `lua_translator@*wanxiang.super_calculator`，触发前缀为 `^V.*$`，即以大写 `V` 开头。

* **触发方式**：输入大写 `V`，后接表达式或功能引导键，例如 `V1+2*3`。进入该模式后，候选框会显示「计算器」相关提示。

* **基础运算**：支持四则运算、括号、幂、阶乘，以及常数和数量级缩写。

  阶乘可以使用 `5!` 或 `fact(5)`；常数支持 `pi`、`e`；数量级缩写支持 `b`（百）、`q` / `k`（千）、`w`（万）、`m`（百万）、`y`（亿）、`g`（十亿）等直接参与运算。

  例如：`V3w+2q` → `32000`。

* **输入示例**：

  1. `V1+2*3` → `7`（表达式求值）

  2. `Vsqrt(2)` → 平方根；`Vsin(30)` / `Vcos(60)` / `Vtan(45)` → 三角函数，弧度与角度模式可通过 `rad` / `deg` 区分

  3. `Vxsqz(3.2)` → `4`（向上取整）、`Vxxqz(3.8)` → `3`（向下取整）、`Vmod(10,3)` → `1`（求余）

  4. `Vfact(5)` → `120`、`Vnrt(8,3)` → `2`（8 开 3 次方）、`Vvar(1,2,3)` → 方差

* **数学求解与功能引导键**：

  * **方程**：`yyyc`（一元一次）、`eyyc`（二元一次）、`yyec`（一元二次）、`yysc`（一元三次）、`yysc2`（一元四次）

  * **函数解析式**：`dxf`（点斜式一次）、`ldf`（两点式一次）、`ybs`（一般式二次）、`dds`（顶点式二次）

  * **几何**：`sjx1`（三边长求三角形面积）、`zdbx`（正多边形面积）、`cesd`（圆方程）、`sjxx`（三角形三心坐标）

  * **数列**：`dcsl`（等差前 n 项和）、`dbsl`（等比前 n 项和）、`tx`（已知两项求通项公式）

  * **数论**：`gys`（最大公因数）、`gbs`（最小公倍数）、`zhs`（组合数）、`pls`（排列数）、`zys`（质因数分解）、`zzs`（找质数）、`ggs`（勾股数）

  * **其他工具**：`dwhs(数字,'原单位','目标单位')`（单位换算）、`jzzh(数字,原进制,目标进制)`（进制转换）、`sjs`（随机数）、`tfp`（24 点）等，共收录上百个数学与工程函数。

  * 示例：`Vyyec(1,2,-3)` 用于求解一元二次方程；`Vdwhs(1,'km','m')` 用于单位换算；`Vjzzh(255,10,16)` 用于将十进制数转换为十六进制。

> **配置说明**：完整的功能引导键和参数写法以 `lua/wanxiang/super_calculator.lua` 文件头注释为准。默认提示文字、触发前缀等内容可以在 YAML 的 `calculator` 配置段以及 `recognizer/patterns/calculator` 中调整。
