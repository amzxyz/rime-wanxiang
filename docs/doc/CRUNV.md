## 🪢 **C** 模式：仿 Linux 系统 Compose 合成字符

当你需要输入那些键盘上根本没有对应按键的特殊符号、带调字母、标点组合时，这是最直接的物理外挂——完全复刻 Linux/X11 的 Compose 机制。

* **触发方式**：大写 `C` 开头 + 依次键入 Compose 序列（如果命中了Compose序列，结果会被推到首选，此时可按空格上屏）。

* **标点命中制（死路自动上屏）**：所有可键入标点（`!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~` 等）统一采用"命中制"门控——只有当接入该标点后新序列能**完整命中**某条 Compose 编码、或成为某编码的**真前缀**时，它才进入序列参与合成；否则视为死路，引擎会直接把**前面的所有内容 + 该标点对应的中文全角标点**一起上屏并退出 C 模式。

  这样既能保留含标点的合法序列（如 `C,` `A` → `Ą`、`C!` → `¡`、`C:-` → `÷`），又让随便敲出的无效序列里的标点照常上屏，不会被卡死在 C 模式里。

  * 示例：`C` `w` `,` → 上屏 `Cw，`（`w` 是死路，字面 `Cw` 随中文逗号一起上屏）；`C` `a` `,` `,` → 上屏 `Ca，`（`Ca,` 已命中、再按逗号不成新序列）；反之 `C` `,` `A` 仍能正常合成 `Ą`。

* **小键盘与主键区分工**：小键盘所有可键入字符的按键（数字 `0-9`、运算符 `+-*/=`、以及小键盘 `,` `.`）一律无条件参与 C 模式合成、且不吞键（小键盘 Enter 透传给 RIME 默认处理）；主键区数字 `1..9,0` 在 C 模式下仍用于选词，主键区的 `-` `=` 仍用于翻页（透传交给 RIME），都不会误进序列。

* **左Alt有妙用**：在只有主键盘可用的情况下，你可以按住左Alt使用主键盘的数字键或`-` `=`参与Compose。

* **实战演示**：输入 **`C`** 后跟着敲：

  1. `'` `e` → `é`（重音字母）

  2. `"` `a` → `ä`（变音字母）

  3. `o` `c` → `©`（版权符号）

  4. `-` `-` → `—`（破折号）

  5. `(` `c` `)` → `©`、`?` `?` → `¿` 等，共收录 **1229** 条合成序列。

## 💴 **R** 模式：数字与财务金额大写

财务报账、填写合同的绝对效率利器。免去任何繁琐的脑内转换和错字风险。

* **触发方式**：大写 `R` 开头 + 一串阿拉伯数字。

* **实战演示**：输入 **`R1234`**，引擎会瞬间为你生成：

  1. `一千二百三十四` (标准中文数字)

  2. `壹仟贰佰叁拾肆元整` (标准财务大写)

  3. `一二三四` (纯汉字直译) 等多种格式。

!!! success "独家操作优化：极速盲选上屏"
    为了打破常规数字选词的冲突，在 R 模式下，选词体验被进行了重构：

    * **字母映射**：你可以直接敲击键盘上的 **`q, w, e, r, t, y...`** 键，它们依次代表第 1 到 6 个候选项，实现按键不位移的极速上屏。

    * **传统兼容**：当然，你依然可以使用 `↑` `↓` 方向键来上下移动焦点进行回车确认。

## 🔣 **U** 模式：Unicode 底层精准定字

当你知道某个生僻字或特殊符号的 Unicode 编码，但完全不知道它怎么读时，这是最直接的物理降维打击。

* **触发方式**：大写 `U` 开头 + 16 进制 Unicode 编码。

* **实战演示**：输入 **`U62fc`**，候选框会直接丢出对应的汉字「拼」。

## 📅 **N** 模式：极速日期录入

在大写字母 `N` 后紧跟数字，即可触发安全占位逻辑的数字日期模式，彻底终结手动敲击年月日符号的烦恼。输入完毕后，可直接使用数字键上屏，同时**完美兼容 `q, w, e...` 代替数字键极速上屏**。

* **4位数模式 (月日)**：输入 `N0101` 或 `N0312`，系统会自动补全当前的年份。

* **8位数模式 (年月日)**：输入 `N20250315`，直接输出完整指定的年月日格式。

> **💡 极客定制**：N 模式同样继承了强大的自定义能力（参考时间日期），它的输出类型、格式、顺序、候选数，每一项均可在 YAML 配置文件中由你一手掌控。

## 🧮 **V** 模式：超级计算器

把输入法变成随身的科学计算器与数学求解器。底层由 `super_calculator.lua` 实现，注册为 `lua_translator@*wanxiang.super_calculator`，触发前缀 `^V.*$`（即大写 `V`）。

* **触发方式**：大写 `V` 开头 + 表达式或功能引导键（如 `V1+2*3`）。候选框提示「计算器」。

* **基础运算**：四则运算、括号、幂、阶乘（`5!` 或 `fact(5)` → 120）、常数 `pi`/`e` 以及数量级缩写 `b`(百) `q`/`k`(千) `w`(万) `m`(百万) `y`(亿) `g`(十亿) 等可直接参与运算，例如 `V3w+2q` → `32000`。

* **实战演示**：

  1. `V1+2*3` → `7`（表达式求值）

  2. `Vsqrt(2)` → 复数的平方根；`Vsin(30)`/`Vcos(60)`/`Vtan(45)` → 三角函数（弧度/角度参见 `rad`/`deg`）

  3. `Vxsqz(3.2)` → `4`（向上取整）、`Vxxqz(3.8)` → `3`（向下取整）、`Vmod(10,3)` → `1`（求余）

  4. `Vfact(5)` → `120`、`Vnrt(8,3)` → `2`（8 开 3 次方）、`Vvar(1,2,3)` → 方差

* **数学求解（部分引导键）**：方程 `yyyc`(一元一次) / `eyyc`(二元一次) / `yyec`(一元二次) / `yysc`(一元三次) / `yysc2`(一元四次)；函数解析式 `dxf`(点斜式一次) / `ldf`(两点式一次) / `ybs`(一般式二次) / `dds`(顶点式二次)；几何 `sjx1`(三边长求三角形面积) / `zdbx`(正多边形面积) / `cesd`(圆方程) / `sjxx`(三角形三心的坐标)；数列 `dcsl`(等差前n项和) / `dbsl`(等比前n项和) / `tx`(已知两项求通项公式)；数论 `gys`(最大公因数) / `gbs`(最小公倍数) / `zhs`(组合数) / `pls`(排列数) / `zys`(质因数分解) / `zzs`(找质数) / `ggs`(勾股数)；工具 `dwhs(数字,'原单位','目标单位')`(单位换算) / `jzzh(数字,原进制,目标进制)`(进制转换) / `sjs`(随机数) / `tfp`(24点) 等，共收录上百个数学与工程函数。

  * 示例：`Vyyec(1,2,-3)` 求解一元二次方程、`Vdwhs(1,'km','m')` 做单位换算、`Vjzzh(255,10,16)` 把十进制转十六进制。

> **💡 极客定制**：完整的功能引导键与参数写法以 `lua/wanxiang/super_calculator.lua` 文件头注释为准；默认提示文案、前缀等可在 YAML 的 `calculator` 段与 `recognizer/patterns/calculator` 中调整。
