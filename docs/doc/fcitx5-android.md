# Fcitx5-Android (小企鹅) 部署指南

欢迎在 Android 平台使用万象。Fcitx5-Android（小企鹅输入法）支持通过中州韵（Rime）插件运行万象方案。由于较新版本的 Android 对 `Android/data` 目录有更严格的权限限制，部署时需要特别注意文件导入方式和目录权限。

[:octicons-download-24: 前往 GitHub Releases 获取最新版](https://github.com/fxliang/fcitx5-android/releases)

*注：该版本支持较完整的键盘自定义功能，适合需要自行调整键盘布局和外观的用户。*

[:octicons-download-24: 前往此处获取小企鹅九键版本](https://ime.lutrip.com/)

*注：九键用户可以配合万象九键方案使用。*

---

### 1. 安装与初始化文件夹

1. 安装 Fcitx5-Android 后，先在应用内添加 **【中州韵】（Rime）插件**。
2. 添加并初始化插件后，Fcitx5-Android 会自动在应用数据目录中创建对应的 Rime 用户文件夹。

!!! warning "不要手动创建 Rime 用户目录"
    如果误删了应用自动生成的 Rime 文件夹，不要直接在文件管理器中手动建立同名目录。

    手动创建的目录可能无法获得与应用一致的访问权限，导致 Fcitx5-Android 无法正常识别或读取其中的文件。

    遇到这种情况，请返回 Fcitx5-Android 设置，重新配置或重新添加中州韵插件，由应用重新创建对应的 Rime 用户目录。

---

### 2. 定位 Rime 用户目录

建议通过 **中州韵设置 → 用户目录** 直接调用 Android 文件管理器进入对应位置，优先使用系统自带的文件管理器。

Rime 用户目录通常位于：

```text
/storage/emulated/0/Android/data/org.fcitx.fcitx5.android/files/data/rime/
```

实际操作时不必特别关注前半部分的完整绝对路径。通过应用跳转进入目录后，重点确认当前位于 `data` 目录下的 `rime` 文件夹。

`data` 目录中可能同时存在 `pinyin` 等其他文件夹，万象方案需要放入的是：

```text
data/rime/
```

请确认方案文件最终位于 `rime` 目录中，不要误放到其他相邻目录。

---

### 3. 置入方案与注意文件权限

将万象方案压缩包解压后，把其中的**所有文件和文件夹**放入上述 Rime 用户目录，同时将语法模型 **`wanxiang-lts-zh-hans.gram`** 一并放入。

注意应复制压缩包内部的方案内容，不要将解压后的最外层目录再次整体套入 `rime` 文件夹，否则会造成目录层级错误。

!!! danger "Android/data 目录的文件权限"
    Fcitx5-Android 的数据目录位于 Android 的 `Android/data` 下，较新版本的 Android 对该目录实施了严格的访问限制。

    不建议使用 MT 管理器等能够绕过系统存储限制的第三方工具直接强制写入文件。部分写入方式可能导致文件所有者或权限组与 Fcitx5-Android 不一致，从而出现文件无法读取、部署失败、运行卡顿，甚至异常内存占用等问题。

    推荐使用以下方式：

    1. 优先使用 Fcitx5-Android 自带的 **【导入文件】** 功能。该方式通过 Android 的 SAF（Storage Access Framework）完成文件访问，可以避免大多数权限问题。

    2. 也可以使用系统自带文件管理器，在系统允许访问该目录的情况下正常复制文件。

    3. Root 用户如果需要直接写入应用目录，应自行确认相关文件的 `chown`、`chmod` 等权限与 Fcitx5-Android 当前目录保持一致。

!!! info "关于皮肤文件"
    万象压缩包中可能同时包含 `简纯+.trime.yaml` 等皮肤文件，这些文件用于 **同文输入法（Trime）**。

    Fcitx5-Android 不直接读取 Trime 的皮肤配置，因此即使将这些文件复制到 Rime 用户目录，也不会作为小企鹅的键盘皮肤生效。

    Fcitx5-Android 的键盘布局和外观需要通过应用自身提供的配置方式进行设置。

---

### 4. 执行重新部署

完成方案文件和语法模型的导入后，返回 Fcitx5-Android。

首次配置时，应用中的 **【重载配置】** 也可能触发 Rime 自动部署；后续修改方案或配置文件后，一般可以直接点击 **【重新部署】**。

> **首次部署可能需要一定时间**：移动设备需要编译词库、加载语法模型并处理相关 Lua 配置，具体耗时与设备性能和方案规模有关。部署完成前，建议不要反复触发部署或频繁唤出键盘。

部署完成后，检查方案列表中是否已经出现“万象拼音”或“万象拼音 Pro”等对应方案，并确认可以正常切换使用。

---

### 5. 初始指令与个性化切换

部署成功后，万象默认使用以下输入方式：

* **Base 标准版**：默认开启 **全拼**。
* **Pro 增强版**：默认开启 **自然码双拼**。

!!! tip "建议执行一次方案切换指令"
    即使当前默认输入方式已经符合使用习惯，也建议通过斜杠指令主动选择一次需要的拼音方案，使相关配置与当前输入方式保持一致。

    **操作方法**：在任意输入框的中文输入状态下，输入对应的斜杠指令。完成切换后返回 Fcitx5-Android，再执行一次 **【重新部署】**，使新的配置正式生效。
