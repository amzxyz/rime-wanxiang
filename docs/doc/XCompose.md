# 基于 Symbols 的 Compose 符号输入

万象的符号系统支持基于 **Compose 序列**输入特殊字符。

该功能参考 Linux/X11 的 **XCompose** 机制，将常用的 Compose 字符序列整合到万象已有的 `symbols` 符号系统中，并统一使用 `/` 作为引导符。

简单来说：

```text
/ + Compose 序列 → 特殊字符
```

例如：

```text
/'e   → é
/"a   → ä
/oc   → ©
/->   → →
/12   → ½
```

---

## 什么是 XCompose

XCompose 是 Linux/X11 中的一套组合字符输入机制。

许多键盘上没有直接按键的字符，例如：

```text
é
ä
ñ
©
½
≤
→
```

可以通过连续输入一组预设按键得到。

传统 X11 中通常先按 **Compose Key**，再输入对应序列，例如：

```text
Compose + ' + e  → é
Compose + " + a  → ä
Compose + o + c  → ©
Compose + 1 + 2  → ½
```

它的本质是一张：

```text
按键序列 → Unicode 字符
```

的映射表。

万象沿用了这种序列输入方式，但将其直接整合到了已有的 Symbols 符号体系中。

---

## 在万象中使用

万象使用 `/` 作为符号引导键，因此无需额外设置 Compose Key。

直接输入：

```text
/ + Compose 序列
```

即可。

例如：

### 带调字母

```text
/'a   → á
/'e   → é

/"a   → ä
/"o   → ö
/"u   → ü

/~a   → ã
/~n   → ñ

/-a   → ā
/-o   → ō

/^a   → â
/^e   → ê
```

### 数学与常用符号

```text
/->   → →
/<-   → ←
/<=   → ≤
/>=   → ≥

/+-   → ±
/:-   → ÷
/~~   → ≈
```

### 分数

```text
/12   → ½
/13   → ⅓
/14   → ¼
/34   → ¾
/58   → ⅝
/110  → ⅒
```

### 上标与下标

```text
/^1   → ¹
/^2   → ²
/^3   → ³

/_1   → ₁
/_2   → ₂
/_3   → ₃
```

### 圈号字符

```text
/(1)   → ①
/(9)   → ⑨
/(10)  → ⑩
/(20)  → ⑳
/(50)  → ㊿
```

### 其他字符

```text
/oc     → ©
/or     → ®
/tm     → ™
/poo    → 💩
/LLAP   → 🖖
```

## 与原有 Symbols 共用 `/`

Compose 序列与万象原有符号命令使用同一个 `/` 入口。

原有符号输入仍然保持不变，例如：

```text
/yd    → 圆点类符号
/fs    → 分数符号
/jt    → 箭头符号
/xue   → 雪相关 Emoji
/1     → 数字 1 的各种符号形式
```

同时也可以直接输入 Compose 序列：

```text
/'a
/"a
/->
/12
/^2
/(10)
```

因此使用时无需区分不同模式，可以统一理解为：

> **`/` 用于输入特殊符号；既可以输入符号简称，也可以输入 Compose 序列。**

---

## 数字与候选选择

部分 Compose 序列本身包含数字，例如：

```text
/12   → ½
/34   → ¾
/^2   → ²
/_3   → ₃
/(10) → ⑩
```

因此系统会区分：

- 当前数字是否属于有效符号序列；
- 当前数字是否应该用于选择候选。

只有确实属于有效符号编码的数字才会继续进入输入序列。

例如：

```text
/12
```

其中 `2` 属于有效编码，因此可以组成：

```text
/12 → ½
```

但此后继续按：

```text
1
```

不会组成 `/121`，而可以继续用于候选选择。

类似地：

```text
/!!
```

已经得到对应候选后，再按数字 `1`，数字不会继续进入符号编码，而是用于选择第一个候选。

---

## `/1` 等数字命令的字母选词

`/1`、`/2` 等原有数字符号命令通常拥有较多候选。

为了避免数字既作为符号编码又作为候选选择键产生冲突，在 `punct` 符号状态下提供了额外的字母选词能力：

```text
q → 第 1 候选
w → 第 2 候选
e → 第 3 候选
r → 第 4 候选
t → 第 5 候选
y → 第 6 候选
u → 第 7 候选
i → 第 8 候选
o → 第 9 候选
p → 第 10 候选
```

例如输入：

```text
/1
```

出现数字 `1` 的各种符号形式后，可以使用：

```text
q w e r t y u i o p
```

直接选择前 10 个候选。

也可以继续使用方向键、空格或回车进行正常候选操作。

---

## 输入字面 `/`

由于 `/` 本身被用作符号引导键，因此输入两个 `/` 可以直接得到字面斜杠：

```text
// → /
```

为了保留这一输入习惯，与 `//` 冲突的少量 Compose 别名不参与符号编码。

因此日常输入 `/` 的方式保持不变。

---

## 设计特点

当前 Compose 符号输入具有以下特点：

- **统一入口**：所有特殊符号统一使用 `/` 引导。
- **兼容 XCompose 序列**：可以直接使用大量 Linux/X11 常见 Compose 输入习惯。
- **兼容原有 Symbols**：`/yd`、`/fs`、`/jt` 等原有符号命令保持不变。
- **支持字母、数字和标点组合**：可输入带调字母、数学符号、货币符号、分数、上下标等字符。
- **数字按需参与编码**：只有有效符号序列中的数字才继续入码，其余数字仍可用于候选选择。
- **支持字母选词**：`punct` 符号状态下可使用 `q`～`p` 选择前 10 个候选。
- **保留 `// → /`**：不会改变原有斜杠输入习惯。

## 简单记忆

不需要专门记住什么是 Compose Key，只需要记住：

```text
/ = 特殊符号入口
```

知道符号简称时，可以使用：

```text
/yd
/fs
/jt
```

知道 Compose 序列时，可以直接使用：

```text
/'e   → é
/"a   → ä
/->   → →
/12   → ½
/^2   → ²
/(10) → ⑩
```

两种方式共用同一套 Symbols 符号输入系统。
