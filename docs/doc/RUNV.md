# 字母引导功能：R 人民币大写 / U Unicode / N 日期 / V 计算器

> **以下功能均通过大写字母触发。输入时请使用 `Shift + R/U/N/V` 得到对应的大写字母，再继续输入后续内容。**

---


## **R** 模式：数字转换

R 模式用于将阿拉伯数字快速转换为中文数字、金额、科学计数、进制等多种常用表示格式，适用于日常输入、财务、数据处理及工程场景。

* **触发方式**：输入大写 `R`，后接数字；支持整数、小数、负数和比例。

* **常用转换**：

  * **中文数字**：小写、大写、繁体大写、金额写法
  * **前导零逐位读**：如 `R0012` → `〇〇一二`
  * **千分位**：如 `R1234567.89` → `1,234,567.89`
  * **人民币格式**：如 `R1234.5` → `￥1,234.50`
  * **会计负数**：如 `R-1234.5` → `(1,234.50)`
  * **科学计数法**：如 `R12345` → `1.2345×10⁴`
  * **E 计数法**：如 `R12345` → `1.2345E+04`
  * **工程计数法**：如 `R12345` → `12.345×10³`
  * **进制转换**：整数可生成十六进制、二进制和八进制表示
  * **比例转换**：如 `R16:9` → `16∶9`、`十六比九`

* **输入示例**：

  1. `R1234` → `一千二百三十四`、`壹仟贰佰叁拾肆元整`、`1,234`、`￥1,234.00`

  2. `R-1234.5` → `负一千二百三十四点五`、`-1,234.5`、`(1,234.50)`

  3. `R0012` → `十二`、`〇〇一二`

  4. `R12345` → `1.2345×10⁴`、`1.2345E+04`、`12.345×10³`

  5. `R255` → `0xFF`、`0b11111111`、`0o377`

  6. `R16:9` → `16∶9`、`十六比九`

!!! success "R 模式选词方式"
    为避免数字键与输入内容产生冲突，R 模式提供额外的候选选择方式：

    * **字母选词**：可以使用 `q, w, e, r, t, y...` 选择对应位置的候选。

    * **方向键选词**：也可以使用 `↑`、`↓` 移动候选焦点，再按回车确认。

## **U** 模式：Unicode 编码转换

U 模式用于通过 Unicode 码点直接输入字符，并在字符、Unicode 码点、不同进制、程序转义、HTML、UTF-8、UTF-16、URL 编码等多种表示形式之间进行转换。

* **触发方式**：输入大写 `U`，后接 Unicode 码点。裸数字默认按**十六进制**解析，也可以通过前缀明确指定十进制、十六进制、二进制或八进制。

### 不同进制的指定输入

U 模式支持使用一个字母指定输入数字采用的进制：

```text
d = decimal      十进制
h = hex          十六进制
x = 0x           十六进制
b = binary       二进制
o = octal        八进制
```

可以简单记成：

> **d 十、h/x 十六、b 二、o 八**

其中：

* `d` 来自 **decimal**，表示十进制
* `h` 来自 **hex**，表示十六进制
* `x` 对应程序中常见的 **`0x`** 十六进制写法
* `b` 来自 **binary**，表示二进制
* `o` 来自 **octal**，表示八进制

例如，同一个字符「拼」可以使用不同进制输入：

```text
U62fc       → 拼    # 裸输入，默认十六进制
Uh62fc      → 拼    # h = hex
Ux62fc      → 拼    # x = 0x
Ud25340     → 拼    # d = decimal
Ub110001011111100 → 拼
Uo61374     → 拼
U+62FC      → 拼    # Unicode 标准 U+XXXX 写法
```

其中 `U62fc`、`Uh62fc` 和 `Ux62fc` 的含义完全相同，都是按十六进制解析。

!!! tip "为什么裸输入默认十六进制？"
    Unicode 码点通常使用十六进制表示，例如：

    ```text
    U+62FC
    U+1F600
    ```

    因此 U 模式保持这一习惯：

    ```text
    U62fc
    ```

    默认等同于：

    ```text
    Uh62fc
    Ux62fc
    ```

### 纯数字输入的进制歧义

如果输入内容只有数字，例如：

```text
U25340
```

由于没有指定进制，系统会首先按照默认的**十六进制**解释：

```text
0x25340 → 𥍀
```

但 `25340` 本身也可以被理解为十进制，而：

```text
25340₁₀ = 62FC₁₆
```

对应字符正是：

```text
拼
```

因此对于这种纯数字输入，候选中会额外给出一个**十进制解释字符**，方便直接选择：

```text
U25340

𥍀    〔字符·十六〕
拼     〔字符·十进〕
...
```

如果已经明确知道手中的数字是十进制，推荐直接输入：

```text
Ud25340
```

这样系统只按十进制解析，不再产生进制歧义。

### 常用转换结果

以：

```text
U62fc
```

为例，可以得到：

```text
拼                       〔字符〕
U+62FC                   〔码点〕
0x62FC                   〔十六进制〕
25340                    〔十进制〕
0b110001011111100        〔二进制〕
0o61374                  〔八进制〕
\u62FC                   〔Unicode转义〕
\u{62FC}                 〔花括号转义〕
E6 8B BC                 〔UTF-8〕
62FC                     〔UTF-16〕
&#x62FC;                 〔HTML十六〕
&#25340;                 〔HTML十进〕
%E6%8B%BC                〔URL编码〕
```

对于 Emoji 等超过 `U+FFFF` 的字符，同样支持完整转换。

例如：

```text
U1f600
```

可以得到：

```text
😀                       〔字符〕
U+1F600                  〔码点〕
0x1F600                  〔十六进制〕
128512                   〔十进制〕
\U0001F600               〔Unicode转义〕
\u{1F600}                〔花括号转义〕
\uD83D\uDE00             〔JS转义〕
F0 9F 98 80              〔UTF-8〕
D83D DE00                〔UTF-16〕
&#x1F600;                〔HTML十六〕
&#128512;                〔HTML十进〕
%F0%9F%98%80             〔URL编码〕
```

### 输入提示

只输入不同的进制前缀时，候选框会显示对应提示，帮助记忆：

```text
Ud    → 十进制 Unicode 码点
Uh    → 十六进制 Unicode 码点
Ux    → 十六进制 Unicode 码点
Ub    → 二进制 Unicode 码点
Uo    → 八进制 Unicode 码点
U+    → Unicode 标准码点
```

实际使用时只需要重点记住：

```text
U62fc      默认十六进制
Ud25340    明确十进制
Uh62fc     h = hex
Ux62fc     x = 0x
Ub...      b = binary
Uo...      o = octal
```

!!! success "U 模式记忆口诀"
    **d 十、h/x 十六、b 二、o 八。**

    普通 Unicode 输入直接使用 `U + 十六进制码点` 即可；只有拿到十进制、二进制或八进制数字时，才需要额外加对应的进制字母。

!!! tip "Ctrl + U 快速查询"

    在任意存在候选字符的位置(反查、符号、正常文字、表情等)，选中需要查询的候选后按下 `Ctrl + U`，即可直接跳转到 U 模式查看该字符的 Unicode 编码及各种转换结果。

    查询完成后再次按下 `Ctrl + U`，可返回原来的输入状态，方便继续切换其他候选进行查询。

## **N** 模式：日期输入

在大写字母 `N` 后输入数字，可以进入数字日期模式。输入完成后，可以直接使用数字键选择候选，同时支持使用 `q, w, e...` 对应候选位置进行选择。

* **4 位数字模式（月日）**：输入 `N0101` 或 `N0312`，系统会自动补充当前年份。

* **8 位数字模式（年月日）**：输入 `N20250315`，直接生成对应的完整日期格式。

> **自定义说明**：N 模式支持调整输出类型、日期格式、候选顺序和候选数量，具体配置方式可参考时间日期相关配置。

## **V** 模式：超级计算器

V 模式提供表达式计算、数学函数、方程求解、几何计算、数列、数论和单位换算等功能。底层由 `super_calculator.lua` 实现，注册为 `lua_translator@*wanxiang.super_calculator`，触发前缀为 `^V.*$`，即以大写 `V` 开头。

* **触发方式**：输入大写 `V`，后接表达式或功能引导键，例如 `V1+2*3`。进入该模式后，候选框会显示「计算器」相关提示。

* **基础运算**：支持四则运算、括号、幂、阶乘，以及常数和数量级缩写。

  阶乘可以使用 `5!` 或 `fact(5)`；常数支持 `pi`、`e`；数量级缩写支持 `b`（百）、`q` / `k`（千）、`w`（万）、`m`（百万）、`y`（亿）、`g`（十亿）等直接参与运算。

  例如：`V3w+2q` → `32000`。

* **输入示例**：

  1. `V1+2*3` → `7`（表达式求值）

  2. `Vsqrt(2)` → 平方根；`Vsin(30)` / `Vcos(60)` / `Vtan(45)` → 三角函数，弧度与角度模式可通过 `rad` / `deg` 区分

  3. `Vxsqz(3.2)` → `4`（向上取整）、`Vxxqz(3.8)` → `3`（向下取整）、`Vmod(10,3)` → `1`（求余）

  4. `Vfact(5)` → `120`、`Vnrt(8,3)` → `2`（8 开 3 次方）、`Vvar(1,2,3)` → 方差

* **数学求解与功能引导键**：

  * **方程**：`yyyc`（一元一次）、`eyyc`（二元一次）、`yyec`（一元二次）、`yysc`（一元三次）、`yysc2`（一元四次）

  * **函数解析式**：`dxf`（点斜式一次）、`ldf`（两点式一次）、`ybs`（一般式二次）、`dds`（顶点式二次）

  * **几何**：`sjx1`（三边长求三角形面积）、`zdbx`（正多边形面积）、`cesd`（圆方程）、`sjxx`（三角形三心坐标）

  * **数列**：`dcsl`（等差前 n 项和）、`dbsl`（等比前 n 项和）、`tx`（已知两项求通项公式）

  * **数论**：`gys`（最大公因数）、`gbs`（最小公倍数）、`zhs`（组合数）、`pls`（排列数）、`zys`（质因数分解）、`zzs`（找质数）、`ggs`（勾股数）

  * **其他工具**：`dwhs(数字,'原单位','目标单位')`（单位换算）、`jzzh(数字,原进制,目标进制)`（进制转换）、`sjs`（随机数）、`tfp`（24 点）等，共收录上百个数学与工程函数。

  * 示例：`Vyyec(1,2,-3)` 用于求解一元二次方程；`Vdwhs(1,'km','m')` 用于单位换算；`Vjzzh(255,10,16)` 用于将十进制数转换为十六进制。

> **配置说明**：完整的功能引导键和参数写法以 `lua/wanxiang/super_calculator.lua` 文件头注释为准。默认提示文字、触发前缀等内容可以在 YAML 的 `calculator` 配置段以及 `recognizer/patterns/calculator` 中调整。
